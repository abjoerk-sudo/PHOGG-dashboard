PHOGG Retreat Explorer - Greenland glacier dashboard

Upload index.html to the root of a public GitHub repository and enable GitHub Pages (main / root).
The embedded PHOGG glacier points and margin geometries are included in index.html.
The live NunaGIS map, ArcGIS Maps SDK, and KU logo need a network connection.

Data: phogg_decadal_retreat_rates.gpkg and MarginsCombined_MLD_Nov2026_with_Hexagon.gpkg.
The mapped-margin files only contain observation dates and line geometries, not an individual retreat distance for each observation.
Mean across map-filtered points is a simple arithmetic mean of available decadal rates.
